# قائمة المختصرات

| المختصر | المعنى بالإنجليزية | المعنى بالعربية |
|---------|--------------------|------------------|
| **API** | Application Programming Interface | واجهة برمجة التطبيقات |
| **ADR** | Architectural Decision Record | سجل القرارات المعمارية |
| **COD** | Cash on Delivery | الدفع عند الاستلام |
| **CRUD** | Create, Read, Update, Delete | إنشاء، قراءة، تعديل، حذف |
| **CSRF** | Cross-Site Request Forgery | تزوير الطلبات عبر المواقع |
| **CSS** | Cascading Style Sheets | صفحات الأنماط المتتالية |
| **DBMS** | Database Management System | نظام إدارة قواعد البيانات |
| **ERD** | Entity Relationship Diagram | مخطط العلاقات بين الكيانات |
| **FR** | Functional Requirement | متطلب وظيفي |
| **HTML** | HyperText Markup Language | لغة ترميز النص التشعبي |
| **HTTP** | HyperText Transfer Protocol | بروتوكول نقل النص التشعبي |
| **HTTPS** | HTTP Secure | HTTP الآمن |
| **JS** | JavaScript | جافا سكريبت |
| **LTR** | Left-to-Right | من اليسار إلى اليمين |
| **MVC** | Model-View-Controller | نموذج-عرض-تحكم |
| **NFR** | Non-Functional Requirement | متطلب غير وظيفي |
| **ORM** | Object-Relational Mapping | الربط الكائني العلائقي |
| **PHP** | PHP Hypertext Preprocessor | المعالج التمهيدي للنصوص |
| **PSR** | PHP Standards Recommendation | توصيات معايير PHP |
| **RTL** | Right-to-Left | من اليمين إلى اليسار |
| **SDLC** | Software Development Life Cycle | دورة حياة تطوير البرمجيات |
| **SMTP** | Simple Mail Transfer Protocol | بروتوكول نقل البريد البسيط |
| **SQL** | Structured Query Language | لغة الاستعلامات البنيوية |
| **SRS** | Software Requirements Specification | مواصفات متطلبات البرمجيات |
| **TC** | Test Case | حالة اختبار |
| **TLS** | Transport Layer Security | أمان طبقة النقل |
| **UC** | Use Case | حالة استخدام |
| **UI** | User Interface | واجهة المستخدم |
| **UUID** | Universally Unique Identifier | معرّف فريد عالمياً |
| **UX** | User Experience | تجربة المستخدم |
| **WCAG** | Web Content Accessibility Guidelines | إرشادات إمكانية الوصول |
| **XSS** | Cross-Site Scripting | كتابة أكواد عبر المواقع |
