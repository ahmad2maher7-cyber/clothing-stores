# 👕 متجر الملابس الإلكتروني

منصة تجارة إلكترونية متكاملة لبيع الملابس، مبنية بـ Laravel 12.

## 📖 نظرة عامة

متجر ملابس إلكتروني احترافي يدعم 4 أدوار:

- 🛡️ **المشرف** — يدير المنصة والمستخدمين والمتاجر
- 🏪 **التاجر** — يدير متجره ومنتجاته وطلباته
- 👤 **الزبون** — يتسوق ويشتري ويقيّم
- 👀 **الزائر** — يتصفح بدون تسجيل

## ✨ المميزات

### للزبائن
- تصفح المنتجات مع فلاتر متقدمة
- سلة تسوق ديناميكية
- إتمام طلب آمن
- كوبونات خصم
- قائمة المفضلة
- تقييمات ومراجعات
- تتبع الطلبات

### للتجار
- لوحة تحكم شاملة
- إدارة المنتجات والمخزون
- إدارة الطلبات
- كوبونات وعروض
- إعدادات المتجر

### للمشرف
- إدارة المستخدمين والمتاجر
- الموافقة على المتاجر الجديدة
- إحصائيات شاملة

## 🛠️ التقنيات

- **Backend:** Laravel 12 (PHP 8.1+)
- **Database:** MySQL 8.0+
- **Frontend:** Tailwind CSS v4 + Alpine.js
- **Build:** Vite 6
- **Auth:** Laravel Breeze

## 📋 المتطلبات

- PHP >= 8.1
- Composer
- MySQL >= 8.0
- Node.js >= 18
- npm >= 9

## 🚀 التنصيب

```bash
# 1. استنسخ المشروع
git clone https://github.com/ahmad2maher7-cyber/clothing-stores.git
cd clothing-stores

# 2. ثبّت الحزم
composer install
npm install

# 3. انسخ ملف البيئة
cp .env.example .env

# 4. ولّد مفتاح التطبيق
php artisan key:generate

# 5. أعدّ قاعدة البيانات في .env
# ثم نفّذ:
php artisan migrate:fresh --seed

# 6. اربط التخزين
php artisan storage:link

# 7. شغّل المشروع (نافذتان)
npm run dev            # نافذة 1
php artisan serve      # نافذة 2
