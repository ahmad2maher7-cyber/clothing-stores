## 📖 نظرة عامة

متجر ملابس إلكتروني احترافي متعدد المتاجر (**Multi-Vendor**) يدعم أربعة أدوار كاملة، مع لوحة تحكم لكل منها، ونظام دفع آمن، وكوبونات خصم، وتقييمات.

| الدور | الوصف |
|-------|-------|
| 🛡️ **المشرف** | يدير المنصة والمستخدمين والمتاجر والموافقة على التجار الجدد |
| 🏪 **التاجر** | يدير متجره، منتجاته، مخزونه، طلباته، وكوبوناته |
| 👤 **الزبون** | يتسوق، يشتري، يقيّم، ويتتبع طلباته |
| 👀 **الزائر** | يتصفح المنتجات بدون تسجيل |

## ✨ المميزات

### للزبائن
- 🛍️ تصفح المنتجات مع فلاتر متقدمة (السعر، التصنيف، التقييم)
- 🛒 سلة تسوق ديناميكية (Alpine.js)
- 💳 إتمام طلب آمن (Checkout)
- 🎟️ كوبونات خصم
- ❤️ قائمة المفضلة (Wishlist)
- ⭐ تقييمات ومراجعات موثقة (Verified Purchase)
- 📦 تتبع حالة الطلبات

### للتجار
- 📊 لوحة تحكم شاملة مع إحصائيات
- 📦 إدارة المنتجات والمخزون
- 🚚 إدارة الطلبات وتحديث حالتها
- 🎟️ إنشاء وإدارة كوبونات الخصم
- ⚙️ إعدادات المتجر (الاسم، الشعار، الوصف)

### للمشرف
- 👥 إدارة المستخدمين والمتاجر
- ✅ الموافقة على المتاجر الجديدة
- 📈 إحصائيات شاملة (مبيعات، مستخدمين، طلبات)
- 🗂️ إدارة التصنيفات
